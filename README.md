# Personal Portfolio Website

## Project Description

This project is a responsive personal portfolio website created using HTML, CSS, and JavaScript. It introduces me as a Software Engineering student and showcases some of the projects I have worked on.

The website was created as part of a web development assignment to practice the fundamentals of HTML, CSS, JavaScript, responsive design, and AI-assisted development.

## Features

* About Me section with my interests and background
* Projects section showcasing two projects
* Responsive design for desktop, tablet, and mobile screens
* Light and dark mode toggle
* Interactive contact form with a demo confirmation message
* Accessible navigation and form elements
* Project card hover effects

## Projects

### Accessibility-Aware Route Planner

An ongoing software project designed to help blind and visually impaired pedestrians navigate outdoor environments by considering accessibility and safety factors.

### Gym Management System

A completed academic project using JavaFX and SQL to manage gym-related information and records.

## How to Run

No additional software or dependencies are required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## AI-Assisted Development

ChatGPT and Claude were used during the development of this project.

ChatGPT was used to help understand project structure, file organization, and connecting the project to GitHub. Claude was used to generate the initial HTML, CSS, and JavaScript code based on the requirements and content provided.

The generated code was reviewed, tested, and modified. Changes included removing unnecessary placeholder content and unused CSS, personalizing the website content, and adding a project-card hover effect.

More details about the AI-assisted development process can be found in [`docs/ai-usage-report.md`](docs/ai-usage-report.md).
