# Personal Portfolio Website

## Overview

This assignment is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. The website presents my background, interests, projects, and technical skills in a simple and accessible format.

## Features

* Responsive personal portfolio layout
* About Me section
* Projects section showcasing selected projects
* Skills and interests section
* Contact section
* Responsive navigation
* Interactive elements using JavaScript
* Accessible and user-friendly design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Files and Structure

* `index.html` — Main portfolio webpage
* `css/styles.css` — Website styling
* `js/script.js` — JavaScript functionality
* `assets/images/` — Images and project graphics
* `docs/` — Technical documentation and AI usage report

## Documentation

Additional documentation for this assignment can be found in the `docs` folder, including the technical documentation and AI usage report.
